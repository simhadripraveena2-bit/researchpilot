# 5. API endpoints

Base path `/api/v1`. JSON everywhere; errors are RFC 7807
`application/problem+json` with a stable `type` URI and `code`. List endpoints
use cursor pagination (`?cursor=&limit=`) and return `{items, next_cursor}`.
OpenAPI is generated by FastAPI and used to generate the frontend TS client.

## 5.1 Phase 1 — foundation

| Method | Path | Purpose |
|---|---|---|
| GET | `/health` | liveness |
| GET | `/health/ready` | DB + Redis reachable |
| GET | `/health/dependencies` | which integrations are configured/reachable (no secrets) |
| GET | `/projects` | list projects (with counts, last run status) |
| POST | `/projects` | create `{title, topic, description?, settings?}` |
| GET | `/projects/{project_id}` | project detail + stats |
| PATCH | `/projects/{project_id}` | update title/description/settings/status |
| DELETE | `/projects/{project_id}` | archive (soft delete) |
| GET | `/dashboard` | recent projects, running runs, pending checkpoints, saved paper count |

## 5.2 Phase 2 — discovery (Milestone 1)

### Runs
| Method | Path | Purpose |
|---|---|---|
| POST | `/projects/{project_id}/runs` | start a run `{workflow: "discovery", config?: RunConfig}` → `202 {run_id}` |
| GET | `/projects/{project_id}/runs` | run history |
| GET | `/runs/{run_id}` | status, config, manifest, per-source status, counts, errors |
| GET | `/runs/{run_id}/events` | **SSE** stream of `run_events` (supports `Last-Event-ID` resume) |
| GET | `/runs/{run_id}/events/log` | paginated event history (non-streaming) |
| POST | `/runs/{run_id}/cancel` | cancel |
| POST | `/runs/{run_id}/retry` | re-run failed branches (e.g. a source that was down) |

### Checkpoints
| Method | Path | Purpose |
|---|---|---|
| GET | `/runs/{run_id}/checkpoints` | list (pending first) |
| GET | `/checkpoints/{checkpoint_id}` | payload to review |
| POST | `/checkpoints/{checkpoint_id}/decision` | `{status: approved|modified|rejected, decision?, comment?}` → resumes graph |

### Queries & provenance
| Method | Path | Purpose |
|---|---|---|
| GET | `/runs/{run_id}/queries` | all queries sent, per source, counts, status, errors |
| GET | `/queries/{query_id}/results` | ranked results for one query |

### Papers
| Method | Path | Purpose |
|---|---|---|
| GET | `/projects/{project_id}/papers` | filters: `status, role, source, year_from, year_to, q, saved, has_full_text`; sort: `relevance, date, citations` |
| POST | `/projects/{project_id}/papers` | add manually by `{doi|arxiv_id|s2_id|openalex_id}`; resolved against sources, never created from user-typed metadata alone |
| PATCH | `/projects/{project_id}/papers/{paper_id}` | status, tags, note, `is_saved`, pin as seed |
| GET | `/papers/{paper_id}` | canonical metadata + identifiers + authors + `field_sources` |
| GET | `/papers/{paper_id}/provenance` | source records, which run/query found it, merge history |
| GET | `/papers/{paper_id}/references` | outgoing citation edges (paged) |
| GET | `/papers/{paper_id}/citations` | incoming citation edges (paged) |
| POST | `/papers/{paper_id}/merge` | manual merge `{other_paper_id}` |
| POST | `/papers/{paper_id}/split` | revert a merge event |
| GET | `/projects/{project_id}/duplicates` | possible duplicates to review |
| GET | `/projects/{project_id}/citation-graph` | nodes/edges for the project subgraph (`?roles=&min_connectivity=`) |
| GET | `/saved-papers` | saved papers across projects |

### Ad-hoc search (Research Search page)
| Method | Path | Purpose |
|---|---|---|
| POST | `/search` | `{query, sources[], filters}` → synchronous, merged & deduplicated results with per-source status (short timeout; no persistence beyond cache unless saved) |
| POST | `/search/save` | save selected results into a project |

### Reports
| Method | Path | Purpose |
|---|---|---|
| GET | `/projects/{project_id}/reports` | versions |
| GET | `/reports/{report_id}` | structured report JSON |
| GET | `/reports/{report_id}/export?format=md|json|bibtex|csv` | export (LaTeX/PDF in Phase 6) |

## 5.8 SSE event shape

```json
{
  "id": 1842,
  "ts": "2026-11-10T14:03:22Z",
  "run_id": "…",
  "agent": "paper_discovery",
  "type": "source.search.completed",
  "level": "info",
  "message": "OpenAlex returned 50 results for query 3",
  "data": {"source": "openalex", "query_id": "…", "count": 50, "cache_hit": false}
}
```

Event types are an enum documented in the API spec (`run.*`, `node.*`,
`source.*`, `checkpoint.*`, `paper.*`, `error.*`).
